# Подключение к агентам

Одна папка `doc-format` содержит инструкции и скрипты для всех агентов.
Копируйте её целиком, сохраняя `SKILL.md`, `rules`, `profiles` и `scripts`.
Вложенная папка `doc-format/doc-format/` не нужна.

## Установка

Из корня скачанного пакета выполните одну команду для своего агента:

```bash
python3 scripts/install_skill.py --agent codex --project /путь/к/проекту
python3 scripts/install_skill.py --agent claude --project /путь/к/проекту
python3 scripts/install_skill.py --agent cursor --project /путь/к/проекту
```

Для личной установки замените `--project /путь/к/проекту` на `--user`.
Ключ `--dry-run` покажет место установки без записи файлов. Установщик
работает локально, не требует ключей API и не меняет настройки агента.
Существующую папку он не перезаписывает. Для обновления сначала сохраните
текущую версию отдельно от каталогов навыков, затем замените папку целиком.

Можно обойтись без скрипта и скопировать папку вручную:

| Агент | Папка проекта | Личная папка | Вызов |
|---|---|---|---|
| Codex | `.agents/skills/doc-format/` | `~/.agents/skills/doc-format/` | `$doc-format` |
| Claude Code | `.claude/skills/doc-format/` | `~/.claude/skills/doc-format/` | `/doc-format` |
| Cursor | `.cursor/skills/doc-format/` | `~/.cursor/skills/doc-format/` | `/doc-format` |

Если навык не появился, откройте новую сессию агента. Не храните несколько
копий с одним именем в каталогах, которые читает один агент. Cursor также
может обнаружить навыки в общих каталогах и папках совместимости; отдельная
копия для Cursor в этом случае не требуется.
Пути и вызовы описаны в документации
[Claude Code](https://code.claude.com/docs/en/skills),
[Cursor](https://cursor.com/help/customization/skills) и
[Codex](https://learn.chatgpt.com/docs/build-skills).

## Окружение

Нужен Python 3.9+. На Windows вместо `python3` обычно используют `py -3`.
Проверьте среду тем интерпретатором, которым агент будет запускать скрипты:

```bash
python3 scripts/check_environment.py --json
python3 scripts/check_environment.py --require docx-render --json
```

Проверки текста и оформление OOXML используют стандартную библиотеку Python.
Для создания DOCX обычно нужен `python-docx`, для прямого создания PDF
`reportlab`. Для рендера DOCX нужен LibreOffice; для получения изображений
из PDF нужен Poppler или PyMuPDF. Используйте установленные шрифты
с кириллицей и проверьте фактический шрифт после экспорта.

Если программы не видны в `PATH`, укажите `--soffice /путь/к/soffice` и
`--pdftoppm /путь/к/pdftoppm` в проверке среды и в `render_pages.py`.
Команды и ограничения находятся в [rules/formats.md](rules/formats.md).

## Другие среды

Агентам с поддержкой Agent Skills передавайте ту же папку. Если такого
механизма нет, явно попросите агента прочитать `SKILL.md` и связанные правила,
указав абсолютный путь. Не добавляйте весь навык в постоянно загружаемые
`CLAUDE.md`, `AGENTS.md` или правила Cursor.

Для Claude.ai и Claude Desktop/Cowork загрузите ZIP навыка через раздел
управления навыками и включите его. Подробности есть в
[инструкции Claude](https://support.claude.com/en/articles/12512180-use-skills-in-claude).
Архив должен содержать папку `doc-format` с `SKILL.md` внутри.
Папка `~/.claude/skills/` относится к локальному Claude Code и сама по себе
не устанавливает навык в облачный аккаунт.

Локальная установка не переносит программы, шрифты и файлы на удалённую
машину. Наличие папки на компьютере не подтверждает её доступность в облачной
сессии. Проверяйте окружение там, где агент выполняет задачу.
Без выполнения команд и просмотра изображений агент сможет проверить лишь
доступную часть документа и должен назвать оставшиеся проверки.
